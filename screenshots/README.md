# Screenshots

Place your **own verified AWS Console screenshots** in this folder.

Suggested filenames:
- `01-vpc-subnets.png`
- `02-ec2-instances.png`
- `03-alb-listeners.png`
- `04-target-group-health.png`
- `05-security-groups.png`
- `06-application-test.png`

Before uploading, hide credentials, access keys, private keys, session tokens, and any information you do not want public. Do not use reference images from the internet as evidence of your own deployment.
